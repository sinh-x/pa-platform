### Reproduction

Run from the selected worktree, with a **new** directory under this deployment's
`artifacts/checks`; the driver refuses an existing evidence directory. It creates
only an inert fixture, never accepts an existing package as a read target:

```sh
PA_TEST_SELECTED_PI=/nix/store/isaxx2q4ka0ra8fs0fdq337431slzd37-pi-coding-agent-1.4.0 \
PA_TEST_SELECTED_PPA_ROOT=/nix/store/vhij5wj9rgkb9kbijj1vzr1nvc5g8ylb-pa-platform-0.1.179 \
node --import=tsx scripts/dev/verify-guarded-readback.mjs \
  "$PA_DEPLOYMENT_DIR/artifacts/checks/installed-before"
```

Actual exit: 0. Literal write/read results and metadata are retained in
`/home/sinh/Documents/ai-usage/deployments/d-907709/artifacts/checks/installed-before/observations.json`.
The generated fixture has 607 lines and SHA-256
`9669429d4003a65aaab00d3c1672d2c35a0d235091cdef8ec8fbc634c4da198a`.

| Request | Direct installed definition | Publication owner | Acquisition |
| --- | --- | --- | --- |
| Full read | Exact bytes delivered | Delivered | 1 acquire, 3 stable checks, 1 close |
| offset=100, limit=43 | Delivered | Delivered | 1 acquire, 3 stable checks, 1 close |
| offset=1000, limit=43 | LOCAL_SOURCE_UNAVAILABLE | Same | 1 acquire, 2 stable checks, 1 close |

The native write definition reported success; full read text exactly matched the
generated bytes/hash, and metadata remained unchanged. Independently, this live
session's exposed guarded reader delivered the full fixture and offset 100/limit
43; offset 1000 returned the same generic unavailable envelope. After that denial,
no alternate reader was used on that source.

Available worktree code shows why: `bound-local-read.ts` maps every untyped Pi
formatting/pagination exception to a stable-source failure. Thus this code alone
cannot distinguish a successful acquisition followed by a formatter failure from
open/stat/read failures. A safely classified diagnostic correction is justified;
assuming the original package was out of range is not.
